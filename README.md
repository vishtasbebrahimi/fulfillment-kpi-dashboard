# EFA Fulfillment KPI Dashboard (Minimal Demo)

این پروژه یک وب‌اپ مینیمال full-stack است که:

- یک فایل اکسل سفارش‌های ایفا را می‌گیرد (با هدرهای فارسی)
- تاریخ‌های شمسی را به میلادی تبدیل می‌کند
- برای هر سفارش WOCT و Processing Time را حساب می‌کند
- 3 تا KPI ساده نشان می‌دهد: WOCT متوسط، Processing متوسط، تعداد سفارش‌ها

## اجرا

```bash
npm install
npm run dev
```

- سرور روی پورت 3001
- فرانت روی پورت 5173

سپس مرورگر را روی آدرس زیر باز کن:
